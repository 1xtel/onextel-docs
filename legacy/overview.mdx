## Does this apply to you?

Check the base URL your integration calls:

| Base URL | Status |
| --- | --- |
| `api.onexaura.com` | **Current.** See the [API Reference](/api-reference/whatsapp/overview) — nothing here applies to you |
| `api.onex-aura.com` (hyphenated) | Earlier SMS API — documented here |
| `365cx.io` | Earlier WhatsApp and RCS APIs — documented here |

If you are building something new, use the current APIs. This section exists so that
integrations written against the earlier endpoints still have a reference.

<Warning>
These pages describe APIs that are no longer actively developed. Endpoints, parameters, and
procedures may be outdated, deprecated, or no longer functional. Migrate to the current
[API Reference](/api-reference/whatsapp/overview) when you can.
</Warning>

## What is archived here

Two distinct earlier API surfaces are covered.

The **`api.onex-aura.com` SMS platform** combined portal instructions — campaigns, phonebook,
credits, sub-accounts, reports — with developer material: API key generation, send and report
APIs, DLT entity, template and sender-ID registration, and marketing-platform connectors.

The **`365cx.io` WhatsApp and RCS APIs** were a separate surface using token-based
authentication, template-based sends, and delivery callbacks. They are unrelated to the current
API and share no endpoints with it.

Voice and Email appeared in the earlier navigation as "coming soon" but were never published, so
no content exists for them.
