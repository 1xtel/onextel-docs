The International SMS API returns codes in two places:

| Where | Field | What it tells you |
| --- | --- | --- |
| [Submission response](/api-reference/sms-international/send-sms#response) | `code` | Whether OneXtel accepted the message |
| [DLR callback](/api-reference/sms-international/dlr-callback) | `ERRORCODE` | Whether the message was delivered |

## Response codes

| Code | Description | Returned in |
| --- | --- | --- |
| `0` | Submission successful | Submission response `code` |
| `700` | Invalid mobile number | Submission response `code` |
| `000` | Delivered | DLR `ERRORCODE` |
| `011` | Undelivered | DLR `ERRORCODE` |

<Note>
  `0` and `000` are different codes. `0` on the submission response means the message was accepted; `000` on the DLR means it was delivered.
</Note>
