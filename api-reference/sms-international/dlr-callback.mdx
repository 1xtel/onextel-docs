---
title: "DLR callback"
description: "The delivery receipt OneXtel posts to your URL when an international SMS reaches its final delivery state."
keywords: ["international sms", "dlr", "delivery receipt", "callback", "webhook"]
---

After delivery, OneXtel sends a callback (DLR) as a `POST` request to your configured URL, with the final delivery state of the message.

<Note>
  This receipt uses **UPPERCASE** field names. SMS sent to India produces a different receipt. See the [India DLR callback](/api-reference/sms/dlr-callback).
</Note>

## Payload

<CodeGroup>

```json Delivered
{
  "STATUS": "success",
  "STATUSDATETIME": "2025-12-04 13:32:04",
  "MSGID": "36NIhMgNvTJDx21HSsuZzF0XD4C",
  "ERRORCODE": "000",
  "ERRORDESP": "DELIVRD",
  "CLIENTMSID": "123456789",
  "MOBILENUMBER": "971502829916"
}
```

```json Failed
{
  "STATUS": "failed",
  "STATUSDATETIME": "2025-12-04 13:30:47",
  "MSGID": "36NIY3sBLynZlLiMLAAudI1CzhY",
  "ERRORCODE": "011",
  "ERRORDESP": "UNDELIV",
  "CLIENTMSID": "123456789",
  "MOBILENUMBER": "971111111111"
}
```

</CodeGroup>

## Fields

<ResponseField name="STATUS" type="string">
  Final delivery state: `success` or `failed`.
</ResponseField>

<ResponseField name="STATUSDATETIME" type="string">
  When the delivery status was finalised, for example `2025-12-04 13:32:04`.
</ResponseField>

<ResponseField name="MSGID" type="string">
  Unique internal message identifier. The same value as `messageid` on the [submission response](/api-reference/sms-international/send-sms#response).
</ResponseField>

<ResponseField name="ERRORCODE" type="string">
  Delivery code. `000` means delivered. On failure, the delivery error code from the operator mapping. See [Response codes](/api-reference/sms-international/error-codes).
</ResponseField>

<ResponseField name="ERRORDESP" type="string">
  Description of the delivery status. For example, `DELIVRD` for delivered or `UNDELIV` for undelivered.
</ResponseField>

<ResponseField name="CLIENTMSID" type="string">
  Your message reference: the `clientsmsid` you sent with the message.
</ResponseField>

<ResponseField name="MOBILENUMBER" type="string">
  The recipient mobile number.
</ResponseField>
