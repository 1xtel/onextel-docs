The **SMS List API** sends SMS to international destinations. You submit message details as JSON, and OneXtel forwards each message to its recipient.

<Note>
  For SMS to Indian numbers, use the [India SMS API](/api-reference/sms/overview), which carries the DLT fields Indian traffic requires.
</Note>

## Endpoint

| | |
| --- | --- |
| Full URL | `https://api.int.onexglobal.io/api/jsmslist` |
| Endpoint | `/api/jsmslist` |
| Method | `POST` |
| Header | `Content-Type: application/json` |

## Authentication

Authenticate with the `key` field **inside the JSON request body**, not in a header. Generate the key in the portal under **API**. See [API keys](/guides/sms-international/api-keys).

## How a message flows

<Steps>
  <Step title="Submit">
    `POST` one or more messages in the `listsms` array. See [Send SMS](/api-reference/sms-international/send-sms).
  </Step>
  <Step title="Read the submission response">
    Each message comes back under `smslist` → `sms` with a `code`: `0` means the platform accepted it, `700` means the mobile number is invalid. Store the `messageid`.
  </Step>
  <Step title="Receive the delivery receipt">
    When delivery reaches its final state, OneXtel sends a `POST` callback (DLR) to the URL configured for your account. Match it to your message with `MSGID` or `CLIENTMSID`. See [DLR callback](/api-reference/sms-international/dlr-callback).
  </Step>
</Steps>

## Endpoints at a glance

| Endpoint | Method | Purpose |
| --- | --- | --- |
