---
title: "Callback: Delivery Notification"
description: "Callback payload structure for WhatsApp message delivery status updates, conversation details, pricing, and recipient status information."
---

The OnexAura platform posts a Delivery Notification callback to your configured
endpoint when the delivery status of an outbound WhatsApp message changes.

<Note>
The payload below is the structural skeleton exactly as documented: each field's value
shows its JSON path, not sample data. The source does not define field meanings, data
types, or enumerated values — all descriptions on this page are **inferred from the
field names and paths** and all leaf fields are documented as `string` because the
source shows every value as a string placeholder. In particular, the possible values of
`statuses.status` are not listed in the source.
</Note>

## Payload format

```json
{
  "waba_id": "entry.id",
  "custref1": "custref1",
  "custref2": "custref2",
  "custref3": "custref3",
  "custref4": "custref4",
  "custref5": "custref5",
  "entry": [
    {
      "id": "entry.id",
      "changes": [
        {
          "value": {
            "metadata": {
              "display_phone_number": "entry.changes.value.metadata.display_phone_number",
              "phone_number_id": "entry.changes.value.metadata.phone_number_id"
            },
            "statuses": [
              {
                "id": "entry.changes.value.statuses.id",
                "status": "entry.changes.value.statuses.status",
                "timestamp": "entry.changes.value.statuses.timestamp",
                "errors": {
                  "code": "entry.changes.value.statuses.errors.code",
                  "message": "entry.changes.value.statuses.errors.message",
                  "title": "entry.changes.value.statuses.errors.title",
                  "href": "entry.changes.value.statuses.errors.href",
                  "error_data": {
                    "details": "entry.changes.value.statuses.errors.error_data.details"
                  }
                },
                "conversation": {
                  "id": "entry.changes.value.statuses.conversation.id",
                  "origin": {
                    "type": "entry.changes.value.statuses.conversation.origin.type"
                  },
                  "expiration_timestamp": "entry.changes.value.statuses.conversation.expiration_timestamp"
                },
                "pricing": {
                  "category": "entry.changes.value.statuses.pricing.category",
                  "billable": "entry.changes.value.statuses.pricing.billable",
                  "pricing_model": "entry.changes.value.statuses.pricing.pricing_model"
                },
                "recipient_id": "entry.changes.value.statuses.recipient_id"
              }
            ],
            "messaging_product": "entry.changes.value.messaging_product"
          },
          "field": "entry.changes.field"
        }
      ]
    }
  ]
}
```
