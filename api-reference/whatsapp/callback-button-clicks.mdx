---
title: "Callback: Button Clicks"
description: "Callback payload structure for inbound WhatsApp button interactions submitted under incoming message events."
---

When an end user taps a button in a WhatsApp message, the OnexAura platform posts a
Button Click callback to your configured endpoint. Button clicks are inbound button
interactions submitted under incoming message events, so the payload follows the same
structure as [Incoming Messages](/api-reference/whatsapp/callback-incoming-messages)
with a `button` object in place of the message content objects.

<Note>
The payload below is the structural skeleton exactly as documented: each field's value
shows its JSON path, not sample data. The source does not define field meanings, data
types, or enumerated values — all descriptions on this page are **inferred from the
field names and paths** and all leaf fields are documented as `string` because the
source shows every value as a string placeholder.
</Note>

## Payload format

```json
{
  "custref1": "custref1",
  "custref2": "custref2",
  "custref3": "custref3",
  "custref4": "custref4",
  "custref5": "custref5",
  "entry": [
    {
      "id": "entry.id",
      "changes": [
        {
          "value": {
            "messages": [
              {
                "id": "entry.changes.value.messages.id",
                "timestamp": "entry.changes.value.messages.timestamp",
                "type": "entry.changes.value.messages.type",
                "context": {
                  "id": "entry.changes.value.messages.context.id",
                  "from": "entry.changes.value.messages.context.from"
                },
                "from": "entry.changes.value.messages.from",
                "button": {
                  "text": "entry.changes.value.messages.button.text",
                  "payload": "entry.changes.value.messages.button.payload"
                }
              }
            ],
            "metadata": {
              "display_phone_number": "entry.changes.value.metadata.display_phone_number",
              "phone_number_id": "entry.changes.value.metadata.phone_number_id"
            },
            "messaging_product": "entry.changes.value.messaging_product",
            "contacts": [
              {
                "profile": {
                  "name": "entry.changes.value.contacts.profile.name"
                },
                "wa_id": "entry.changes.value.contacts.wa_id"
              }
            ]
          },
          "field": "entry.changes.field"
        }
      ]
    }
  ]
}
```
