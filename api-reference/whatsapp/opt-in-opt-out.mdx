---
title: "Opt In / Opt Out"
description: "Manage WhatsApp marketing and utility message consent: list, add, and remove opt-in and opt-out entries per recipient number."
---

Use these endpoints to manage recipient consent for WhatsApp messaging. Opt-out entries
suppress messages of a given type to a number; opt-in entries record explicit consent.
Each endpoint pair mirrors the same shape for `/opt/out/wa` and `/opt/in/wa`.

<Note>
This page is built entirely from the OneXtel Postman collection (`WhatsApp > Opt In/ Opt Out`
folder). The OneXtel WhatsApp API Guide PDF does not document these endpoints.
</Note>

<ParamField header="apikey" type="string" required>
  API key generated for the TUC associated with the sending phone number. Required on
  every request below.
</ParamField>

## Get Opt Out

Lists numbers currently opted out.

```
GET /opt/out/wa
```

### Sample cURL request

```bash
curl --location 'https://api.onexaura.com/opt/out/wa' \
--header 'apikey: YOUR_API_KEY'
```

<Note>
The source Postman request does not define query parameters or a saved response example
for this listing endpoint — the filter parameters and response schema are not documented.
This is listed as a gap.
</Note>

## Add Opt Out

Adds one or more numbers to the opt-out list for the given message type(s).

```
POST /opt/out/wa
```

<ParamField body="numbers" type="array" required>
  Array of recipient phone numbers to opt out.
</ParamField>
<ParamField body="sender" type="string" required>
  Sender's registered WhatsApp number.
</ParamField>
<ParamField body="message_types" type="array" required>
  Message categories to opt out of. Values: `marketing`, `utility`.
</ParamField>

### Sample JSON payload

```json
{
  "numbers": ["919999999991", "919999999992"],
  "sender": "919888888888",
  "message_types": ["marketing", "utility"]
}
```

### Sample cURL request

```bash
curl --location 'https://api.onexaura.com/opt/out/wa' \
--header 'apikey: YOUR_API_KEY' \
--header 'Content-Type: application/json' \
--data '{
  "numbers": ["919999999991", "919999999992"],
  "sender": "919888888888",
  "message_types": ["marketing", "utility"]
}'
```

## Remove Opt Out

Removes a number from the opt-out list for a given message type.

```
DELETE /opt/out/wa
```

### Query parameters

<ParamField query="number" type="string" required>
  Recipient phone number to remove from the opt-out list.
</ParamField>
<ParamField query="sender" type="string" required>
  Sender's registered WhatsApp number.
</ParamField>
<ParamField query="message_type" type="string" required>
  Message category to remove the opt-out for. Values: `marketing`, `utility`.
</ParamField>

### Sample cURL request

```bash
curl --location --request DELETE 'https://api.onexaura.com/opt/out/wa?number=919999999991&sender=919888888888&message_type=marketing' \
--header 'apikey: YOUR_API_KEY'
```
