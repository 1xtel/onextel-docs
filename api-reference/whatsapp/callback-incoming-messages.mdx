title: "Callback: Incoming Messages"
description: "Callback payload structure for inbound WhatsApp messages, including text, media, location, and related contact metadata."
---

When an end user sends a WhatsApp message to your business number, the OnexAura
platform posts an Incoming Messages callback to your configured endpoint.

<Note>
The payload below is the structural skeleton exactly as documented: each field's value
shows its JSON path, not sample data. The source does not define field meanings, data
types, or enumerated values — all descriptions on this page are **inferred from the
field names and paths** and all leaf fields are documented as `string` because the
source shows every value as a string placeholder.
</Note>

<Note>
The skeleton shows all content objects (`text`, `location`, `image`, `video`, `audio`,
`document`) side by side. Which of these appear in a real callback for a given message
is not stated in the source; the `type` field indicates the message type (inferred).
</Note>
