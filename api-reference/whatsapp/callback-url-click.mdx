When an end user clicks a tracked URL in a WhatsApp message, the OnexAura platform
posts a URL Click callback to your configured endpoint. Unlike the other callback
event types, this payload is a flat JSON object.

<Note>
The payload below is the structural skeleton exactly as documented: each field's value
is a placeholder, not sample data. The source does not define field meanings, data
types, or enumerated values — all descriptions on this page are **inferred from the
field names** and all fields are documented as `string` because the source shows every
value as a string placeholder.
</Note>
