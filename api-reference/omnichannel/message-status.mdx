---
title: "Message Status"
description: "Look up delivery status for one or more messages by message ID or mobile number."
---

The Message Status endpoint returns delivery status for messages you've sent, looked up
either by `messageId` or by `mobileNumber` with a date range.

## Endpoint

```
POST https://api.onexaura.com/status
```

## Headers

<ParamField header="apikey" type="string" required>
  API key issued by OneXtel, used for authentication.
</ParamField>

## Choosing a lookup

You must supply **either** `messageId` **or** `mobileNumber` — never both.

| Lookup by | Date range |
| --- | --- |
| `messageId` | Optional |
| `mobileNumber` | **Required** — `from` and `to` must both be supplied |

<Warning>
Passing `messageId` and `mobileNumber` in the same request returns an error. Supplying neither
does too — one of the two is always required.
</Warning>

## Request body

The request body is a JSON object.

<ParamField body="channel" type="string" required>
  Channel to query — `whatsapp`, `rcs`, or `sms`.
</ParamField>

<Warning>
An earlier source documented this value as `wa`. Working requests use the full channel name
`whatsapp`. Use `whatsapp`; treat `wa` as unverified.
</Warning>

<ParamField body="taId" type="integer">
  Tenant administrator ID. Scopes the query to a tenant.
</ParamField>

<ParamField body="tucId" type="integer">
  TUC ID. Scopes the query to a specific account under the tenant.
</ParamField>

<Note>
`taId` and `tucId` scope the lookup to a tenant and account. They are not needed when the API
key already identifies a single account, but are accepted — and appear in working requests from
tenant-level callers. Confirm with your account team whether your integration needs them.
</Note>

<ParamField body="messageId" type="array">
  Array of message IDs to look up. Required unless `mobileNumber` is supplied, and mutually
  exclusive with it.
</ParamField>

<ParamField body="mobileNumber" type="array">
  Array of recipient mobile numbers, with country code. Required unless `messageId` is
  supplied, and mutually exclusive with it.
</ParamField>

<ParamField body="from" type="string">
  Start of date range, formatted `YYYY-MM-DD HH:mm:ss` — for example
  `"2025-12-17 00:00:00"`. Mandatory when querying by `mobileNumber`.
</ParamField>

<ParamField body="to" type="string">
  End of date range, formatted `YYYY-MM-DD HH:mm:ss` — for example
  `"2025-12-17 23:59:59"`. Mandatory when querying by `mobileNumber`.
</ParamField>

<ParamField body="pageNo" type="integer" default="0">
  Page number for paginated results.
</ParamField>

<ParamField body="limit" type="integer" default="10">
  Number of records to return per page.
</ParamField>

## Example request

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api.onexaura.com/status \
  --header 'apikey: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
  "taId": 10,
  "tucId": 2002,
  "channel": "whatsapp",
  "messageId": [
    "3I7dnaYRaiTVj8f5EgxsoiJrT5R"
  ],
  "pageNo": 0,
  "limit": 100
}'
```

```json Request body (by messageId)
{
  "taId": 10,
  "tucId": 2002,
  "channel": "whatsapp",
  "messageId": [
    "3I7dnaYRaiTVj8f5EgxsoiJrT5R"
  ],
  "pageNo": 0,
  "limit": 100
}
```

```json Request body (by mobileNumber)
{
  "channel": "whatsapp",
  "mobileNumber": ["919999999999"],
  "from": "2025-12-17 00:00:00",
  "to": "2025-12-17 23:59:59",
  "pageNo": 0,
  "limit": 10
}
```

</CodeGroup>
