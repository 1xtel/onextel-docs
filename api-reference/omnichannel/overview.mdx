---
title: "OmniChannel API Overview"
description: "Send SMS, RCS, and WhatsApp messages — with automatic fallback — through a single OneXtel API endpoint."
---

The OmniChannel Send API is a single endpoint that spans all three OneXtel messaging
channels — **SMS**, **RCS**, and **WhatsApp** — plus an optional automatic fallback
mechanism between channels. Instead of integrating separately with each channel's send
API, you can call one endpoint and route messages across channels from a single
request payload.

## Base URL

```
https://api.onexaura.com
```

<Note>
All endpoints in this section use the `{{domain}}` variable from the OneXtel Postman
collection, which resolves to `https://api.onexaura.com`.
</Note>

## Authentication

Every request is authenticated with an `apikey` header carrying the API key issued to
your OneXtel account.

<ParamField header="apikey" type="string" required>
  API key issued by OneXtel, used for authentication.
</ParamField>

## The send endpoint

```
POST https://api.onexaura.com/oapi/send_sms
```

Despite the `send_sms` path, this single endpoint accepts payloads for SMS, RCS, and
WhatsApp — the channel is determined by which top-level key (`sms`, `wa`, or `rcs`) you
include in the request body. Adding a `fallback` object to the same request enables
automatic fallback to a secondary channel if the primary channel doesn't deliver within
a configured wait time.
