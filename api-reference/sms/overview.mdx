SMS to Indian numbers goes through the **Omni send endpoint** — the same endpoint used for
WhatsApp and RCS, with `channel` set to `sms`. You submit message details as a JSON payload and
the platform delivers to the recipients.

<Note>
For destinations **outside India**, use the
[International SMS List API](/api-reference/sms-international/overview) — a different host, a
different authentication scheme, and no DLT fields.
</Note>

## Endpoints

```
POST https://api.onexaura.com/send_sms
POST https://api.onexaura.com/oapi/send_sms
```

Both are live and take the same key and body. `/send_sms` carries the fuller SMS feature set;
`/oapi/send_sms` is the shared Omni endpoint used for WhatsApp and RCS too, and is the one
[channel fallback](/api-reference/omnichannel/fallback) requires. See
[Endpoints](/api-reference/sms/send-sms-omni#endpoints).

## Authentication

An `apikey` HTTP header carrying your account's API key — see
[API keys](/guides/platform/api-keys).

<ParamField header="apikey" type="string" required>
  Your OneXtel API key.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  `application/json`
</ParamField>

## DLT is mandatory

Indian SMS traffic is regulated by TRAI's DLT framework. Every message must reference a
registered entity, sender ID, and template, supplied on the send as `entityId` and `templateId`.
Messages that fail these checks are rejected before they reach an operator — see
[DLT registration](/guides/sms/dlt) and the `201`–`227` band in
[SMS error codes](/api-reference/sms/error-codes).

## How it compares to international SMS

| | India | [International](/api-reference/sms-international/overview) |
| --- | --- | --- |
| Host | `api.onexaura.com` | `api.int.onexglobal.io` |
| Path | `/send_sms` or `/oapi/send_sms` | `/api/jsmslist` |
| Authentication | `apikey` header | `key` in the body |
| Message array | `sms` | `listsms` |
| DLT fields (`templateId`, `entityId`) | Required | Not used |
| Shared with WhatsApp and RCS | Yes — same endpoint | No — SMS only |
| [Channel fallback](/api-reference/omnichannel/fallback) | Yes | No |
| DLR field style | camelCase | UPPERCASE |

<Tip>
If you send WhatsApp or RCS as well as SMS to India, this endpoint gives you one integration, one
API key, and fallback between channels.
</Tip>

| Endpoint | Method | Purpose |

| [`/send_sms`](/api-reference/sms/send-sms-omni) | POST | Send SMS, with DLT fields, custom references, campaign tagging, and URL shortening |
