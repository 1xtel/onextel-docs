SMS to Indian numbers is sent to `/send_sms`, by `POST` or `GET`. You submit message details and
the platform delivers to the recipients, one-to-one, one-to-many, or many-to-many in a single
call. `/send_sms` carries SMS only: to send WhatsApp or RCS, or to fall back from one channel to
another, use `/oapi/send_sms`, described in the
[OmniChannel API](/api-reference/omnichannel/overview).

<Note>
For destinations **outside India**, use the
[International SMS List API](/api-reference/sms-international/overview) — a different host, a
different authentication scheme, and no DLT fields.
</Note>

<Tip>
Check a request body before you send it with the [payload validator](/api-reference/payload-validator).
It shows what the API would reject, without sending anything.
</Tip>

## Endpoint

```
POST https://api.onexaura.com/send_sms
```

## Authentication

An `apikey` HTTP header carrying your account's API key — see
[API keys](/guides/platform/api-keys).

<ParamField header="apikey" type="string" required>
  Your OneXtel API key.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  `application/json`
</ParamField>

## DLT is mandatory

Indian SMS traffic is regulated by TRAI's DLT framework. Every message must reference a
registered entity, sender ID, and template, supplied on the send as `entityId` and `templateId`.
Messages that fail these checks are rejected before they reach an operator — see
[DLT registration](/guides/sms/dlt) and the `201`–`227` band in
[SMS error codes](/api-reference/sms/error-codes).

## How it compares to international SMS

| | India | [International](/api-reference/sms-international/overview) |
| --- | --- | --- |
| Host | `api.onexaura.com` | `api.int.onexglobal.io` |
| Path | `/send_sms` | `/api/jsmslist` |
| Authentication | `apikey` header | `key` in the body |
| Message array | `sms` | `listsms` |
| DLT fields (`templateId`, `entityId`) | Required | Not used |
| DLR field style | camelCase | UPPERCASE |

## Endpoints at a glance

| Endpoint | Method | Purpose |
| --- | --- | --- |
| [`/send_sms`](/api-reference/sms/send-sms-omni) | POST or GET | Send SMS, with DLT fields, custom references, campaign tagging, and URL shortening |
| [`/surl`](/api-reference/sms/url-shortener) | GET | Shorten a URL without sending an SMS |
| [`/get_status`](/api-reference/sms/get-status) | POST or GET | Pull the delivery status of a message by UUID |
| [DLR callback](/api-reference/sms/dlr-callback) | POST (inbound, to your URL) | Receive the final delivery state |
| [Clicker callback](/api-reference/sms/clicker-callback) | POST (inbound, to your URL) | Receive link-click events |
| [Message status](/api-reference/omnichannel/message-status) | POST | Poll for status instead of receiving it, across channels |
