---
title: "Get a message"
description: "Read a message, its current status and the time of every status change."
openapi: "/api-reference/truecaller/openapi.yaml GET /v1/messages/{id}"
---

`events` lists each status with the time it was recorded, so you can see how long delivery and
read took. A message never moves backwards: a late `delivered` receipt after `read` is ignored.
