---
title: "Webhooks"
description: "Receive message and campaign events at your own endpoint, signed so you can verify them."
---

Instead of polling, add an endpoint in the Truecaller campaigns portal under
**Developers → Webhooks** and pick the events you want. OneXtel POSTs each event to your URL as
JSON.

## Events

| Event | When |
| --- | --- |
| `message.sent` | Truecaller accepted the message |
| `message.delivered` | It reached the person's phone |
| `message.read` | The person opened it |
| `message.failed` | It could not be sent; `data.error` says why |
| `campaign.started` | A campaign began sending |
| `campaign.completed` | A campaign finished |

## Verify the signature

Every request carries `x-onextel-signature: t=TIMESTAMP,v1=SIGNATURE`. `SIGNATURE` is the
HMAC-SHA256 (hex) of `TIMESTAMP.RAW_BODY` with the endpoint's signing secret, shown when you add
the endpoint. Reject requests whose timestamp is more than 5 minutes old.

```js Node.js
import crypto from 'node:crypto';

function verify(rawBody, header, secret) {
  const { t, v1 } = Object.fromEntries(header.split(',').map((p) => p.split('=')));
  const expected = crypto.createHmac('sha256', secret).update(`${t}.${rawBody}`).digest('hex');
  const fresh = Math.abs(Date.now() / 1000 - Number(t)) < 300;
  return fresh && crypto.timingSafeEqual(Buffer.from(v1), Buffer.from(expected));
}
```

## Retries

Reply with any `2xx` within 10 seconds. Anything else is retried up to 6 times over about 8
hours. The portal shows each delivery with its response, and lets you retry or send a test event.
