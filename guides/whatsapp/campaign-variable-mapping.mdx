Variable mapping controls how values such as Name, OTP, URL, and other fields are inserted into the message template during campaign creation. The platform supports two types of variable mapping: **Static** and **Dynamic**.

This page follows on from [Create a WhatsApp campaign](/guides/whatsapp/campaign-create). Click **Variable Mapping** in the campaign builder to open this section.

## The variable mapping panel

The panel has two areas:

- **Data Sources** (left) — **File Columns** extracted from your uploaded recipient file (for example `phone_number`, `name`, `OTP`, `url`) and **Static Values** you define yourself.
- **Variables** (right) — the template's placeholders (`{{1}}`, `{{2}}`, `{{3}}`, …) waiting to be filled, grouped by where they sit: **Header**, **Body**, button variables, and each card of a carousel. Drag a data source onto each variable's drop zone.

The bar shows **Total Variables**, **Mapped** and **Progress**, and the template preview on the right updates as you map. When every placeholder is filled, the panel shows **All variables mapped successfully**.

## Static mapping

Use static mapping when the value should remain the same for all recipients — ideal for fixed URLs, brand names, or common text.

<Steps>
  <Step title="Open Variable Mapping">
    Click **Variable Mapping**.
  </Step>
  <Step title="Enter the fixed value">
    In **Static Values**, enter the fixed value.
  </Step>
  <Step title="Add the value">
    Click **+**. The value appears in the Static Values list.
  </Step>
  <Step title="Map it to a placeholder">
    Drag the static value into the required placeholder (for example `{{3}}`).
  </Step>
  <Step title="Verify">
    The same value will appear for all recipients.
  </Step>
</Steps>

## Dynamic mapping

Use dynamic mapping when the value should change per recipient, pulled directly from the uploaded file — perfect for OTPs, names, and links.

<Steps>
  <Step title="Review file columns">
    In **File Columns**, view the fields extracted from your uploaded recipient file.
  </Step>
  <Step title="Map the first column">
    Drag the required column (for example, `name`) to the placeholder `{{1}}`.
  </Step>
  <Step title="Map the remaining columns">
    Drag another column (for example, `address`) to `{{2}}`, and drag the `phone_number` column to `{{3}}`.
  </Step>
  <Step title="Done">
    All variables auto-populate per recipient during execution.
  </Step>
</Steps>

<Tip>
You can mix both types in one campaign — for example, a dynamic `name` in `{{1}}` and a static brand URL in `{{2}}`.
</Tip>

## Custom reference parameters

Under **Custom Reference Parameters** you can set **Cust Ref 1** to **Cust Ref 5** — your own
values, such as a campaign code or order batch. They are returned in reports and in callbacks, so
your systems can match each delivery report to its source. All five are optional.

## Additional Settings

Click **Additional Settings** in the campaign builder.

### Short and Track URLs in Body Variables

Shortens the links in the body variables and tracks every click, so clicks appear in the URL
views of [WhatsApp reports](/guides/whatsapp/reports).

<Steps>
  <Step title="Switch it on">
    Turn on **Short and Track URLs in Body Variables**.
  </Step>
  <Step title="Pick the domain">
    Pick the **Domain** the short links use.
  </Step>
  <Step title="Choose which links">
    Choose **Short and Track all Urls**, or pick the specific body variables whose links should be
    shortened.
  </Step>
  <Step title="Capture location (optional)">
    Tick **Get Location** to record the location of each click.
  </Step>
</Steps>

### Fallback

Fallback re-sends the message on another channel — RCS or SMS — when WhatsApp fails or doesn't
confirm delivery in time. Add recipients first, then:

<Steps>
  <Step title="Turn on Fallback">
    Turn on **Fallback**, choose a **Fallback Configuration**, and click **Apply Fallback**.
  </Step>
  <Step title="Set the wait time">
    Enter the wait time, in seconds, before the first fallback starts.
  </Step>
  <Step title="Fill in the fallback message">
    Fill in the fields for each fallback channel. Values can be fixed text, file columns such as
    `@name`, or a mix — for example `Dear @name, your order has shipped`.
  </Step>
</Steps>

<Warning>
Set a message validity period on the WhatsApp template before you use it with fallback. Without
one, the customer can receive the late WhatsApp message *and* the fallback. See
[Create WhatsApp templates](/guides/whatsapp/templates).
</Warning>

Fallback configurations are created under **Channels → Fallback** — see
[Configure fallback](/guides/omnichannel/configure-fallback).
