---

The Campaign feature on the OnexAura portal creates, manages, and sends bulk or targeted messages across multiple channels, including WhatsApp and RCS. Use it to promote offers, share updates, and deliver notifications efficiently.

- **WhatsApp Campaigns** — send approved message templates, images, and documents through the verified WhatsApp Business API.
- **RCS Campaigns** — deliver rich media, interactive buttons, and branded layouts to users' native messaging apps (covered in the RCS Campaign guide).

Each campaign includes customization, scheduling, and analytics to track delivery, read rates, and overall engagement.

## Open the campaigns dashboard

<Steps>
  <Step title="Open Channels">
    In the left pane of the platform, click **Channels**.
  </Step>
  <Step title="Select a channel">
    Select the **WhatsApp** channel.
  </Step>
  <Step title="Open Campaigns">
    Click **Campaigns**. The campaigns dashboard (**View Campaign** page) appears.
  </Step>
</Steps>

## What the dashboard shows

The campaigns dashboard displays all campaigns created for the WhatsApp and RCS channels as cards. Each campaign card shows:

| Field | Description |
| --- | --- |
| Campaign name | The unique title given at creation. |
| Template | The message template used. |
| File | The uploaded recipient file, if any. |
| Records | The number of recipient records. |
| Creation date | When the campaign was created. |
| Created by | The user who created the campaign. |
| Status | `Created`, `Draft`, or `Completed`. |

## Dashboard actions

- **Search** — use the search box to find a campaign by name.
- **Filter** — narrow the list by channel, template, type/status, or date.
- **Clone Campaign** — duplicate an existing campaign instead of rebuilding it.
- **New Campaign** — click **+ New Campaign** in the top right to start a new campaign. See [Create a WhatsApp campaign](/guides/whatsapp/campaign-create).

The list is paginated; use **Prev** and **Next** at the bottom of the page to move between pages.
