OneXtel RCS (Rich Communication Services) is an advanced messaging platform
that enhances traditional SMS with rich features, including images, videos,
carousels, quick reply buttons, and file sharing. It works over mobile
networks or Wi-Fi, offering secure, interactive, and real-time communication.
Businesses use RCS to deliver engaging promotions, transactional updates,
and customer support.

OneXtel's RCS serves as a leading platform for business communication
solutions, enabling brands to create connected user experiences with a
strong focus on integrated telecommunications. It helps businesses establish
their identities and manage engagement activities across multiple verticals.

Messaging services are offered through RCS mediums. For each medium, a
channel can be created to establish a communication line with a defined set
of end users. Since RCS is managed by Google, signing up on these platforms
is required, followed by providing account details on RCS. An Embedded
Sign-up option is available to configure RCS accounts.

## Capabilities

- **Rich cards**: A single message with media (image or video), a title,
  description, and buttons — the **Rich Card Stand Alone** template type.
- **Carousels**: Multiple rich cards displayed in a scrollable, swipe-able
  format — the **Rich Card Carousel** template type.
- **Suggested actions / reply buttons**: Quick reply, dialer action (call),
  URL action (open a webpage), and dynamic link tracking for monitoring
  button and link engagement.
- **Branded, app-like experience**: Read receipts, media sharing, and
  branded messages delivered directly within the recipient's native
  messaging app.

## Channels in OneXtel

The **Channels** section lets you configure and manage OneXtel's different
communication channels:

| Channel | Description |
|---|---|
| **SMS** | Traditional text messaging available on all mobile phones. Supports up to 160 characters and works without the internet, making it reliable for basic communication and alerts. |
| **WhatsApp** | Internet-based messaging that supports text, images, videos, voice, and business APIs. Used for rich user engagement through secure and verified accounts. |
| **RCS** | An advanced messaging standard that upgrades SMS. It supports read receipts, media sharing, buttons, and branded messages, providing an app-like experience within the default messaging application. |

## Agent and brand concepts (sender profiles)

RCS messaging in OneXtel is organized around **Sender Profiles** — business
sender identities that ensure messages are sent from authorized identities
with clear classification, helping maintain compliance and message delivery
efficiency. Each sender profile is assigned a **Message Type**:

- **Promotional**: Used to send marketing or offer-related messages.
- **Transactional**: Used to share essential information like updates or
  alerts.
- **OTP**: Used to send one-time passwords for user verification and login.

RCS **Templates** are pre-approved message formats built under a sender
profile and used for customer communication. See
[Templates](/guides/rcs-platform/templates) for details.
