title: "Summary Reports"
description: "Overall, Failure, and URL Summary reports for RCS message delivery and performance in OneXtel."
---

Reports provide insights into message delivery and performance to help
monitor communication efficiency. The RCS **Reports** subtab
(**Channels > RCS > Reports**) contains a **Summary Report** section (this
page) and a **Detail Report** section (see
[Detail Reports](/guides/rcs-platform/reports-detail)).

## Overall Report

The top section displays summary cards showing:

- **Total Submitted**: Number of RCS messages sent.
- **Delivered**: Messages successfully delivered to recipients.
- **Read**: Messages viewed by users.
- **Failed**: Messages that were not delivered.
- **Total Incoming Summary**: Number of incoming messages received from
  users.

### Detailed Breakdown

This table categorizes data by TUC ID and message category (Basic, Rich,
Other). It displays the number of messages submitted, delivered, failed,
read, and button clicks for each category.

### Performance Overview

The Performance Overview section shows a bar chart that visually
represents message performance across categories, comparing the number of
Submitted, Delivered, Failed, and Read messages to help identify trends and
delivery effectiveness.

### Additional features

- **Date & Time** and **TUC** filters allow refined data viewing.
- The **Group By** option organizes results based on selected criteria.
- **Download** enables exporting the report for further analysis.

### Procedure

<Steps>
  <Step title="Open Channels > RCS > Reports">
    In the left pane of the RCS platform, click **Channels**, select
    **RCS**, then click the **Reports** subtab.

    The RCS Report details appear.
  </Step>
  <Step title="Open Overall">
    Click the **Overall** navigation tab.
  </Step>
  <Step title="Select date and TUC">
    Select the required date and time from the dropdown list. By default,
    the report displays data for **Today**. Select a specific TUC or
    **All TUC** from the dropdown list.
  </Step>
  <Step title="Apply filters">
    In the right-hand corner, click the red tick icon to apply filters.
    The report for the selected date and time appears.
  </Step>
  <Step title="Reset (optional)">
    Click **Reset** to clear any applied filters.
  </Step>
  <Step title="Export (optional)">
    Click **Download** to export the report.
  </Step>
</Steps>

## Failure Report

The top section highlights the **Total RCS Failures**, showing the total
number of failed messages during the selected period. It also displays the
**Top RCS Error Type**, which indicates the most common reason for message
failure.

### Detailed RCS Failure Analysis

This table lists the **Error Code**, **Error Message**, and **Count** of
occurrences for each error. It helps identify technical or
delivery-related issues affecting RCS message transmission.

### Additional features

- **Date & Time** and **TUC** filters allow selection of specific data
  periods and TUCs.
- The **Group By** option helps organize results based on preferred
  parameters.
- **Download** enables exporting the failure analysis report for offline
  review and troubleshooting.

  <Step title="Apply filters">
    Click the **red tick** icon to apply filters. The report for the

## URL Summary Report

The top section presents key metrics for URL engagement within RCS
messages.

| Key Metrics | Description |
|---|---|
| **Total URLs** | Number of URLs sent in RCS campaigns. |
| **Total Clicks** | Total number of clicks recorded across all URLs. |
| **Unique Clicks** | Number of distinct users who clicked links. |
| **Avg Clicks/URL** | Average number of clicks per URL. |

### URL Summary Report table

The table lists each URL with details such as Total Clicks, Unique Clicks,
Sender Profile, Campaign Name, Template Name, Message Type, and Category.
It provides a clear view of user interactions and campaign effectiveness.

- **Long URL**: The complete link shared through RCS.
- **Total Clicks** and **Unique Clicks**: Interaction statistics for each
  URL.
- **Sender Profile, Campaign Name, Template Name, and Message Type**:
  Details related to the campaign setup (if available).
- **Category**: Type of message category.
- **Country, API Key, Source, Provider ID**: Technical details for message
  tracking and delivery (displayed when applicable).

### Additional features

- **Search** enables quick access to specific URLs or campaigns.
- **Date & Time** and **TUC** filters allow refined data selection.
- **Download** exports the summary report for performance tracking and
  analysis.
