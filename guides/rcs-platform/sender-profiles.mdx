---
title: "Sender Profiles"
description: "Manage business sender identities for RCS messaging in the OneXtel platform."
---

The **Asset Management** section manages all RCS-related resources,
including Sender Profiles and Templates.

Sender Profiles manages business sender identities for RCS messaging.
Sender profiles ensure that businesses send messages from authorized
identities with clear classification, helping maintain compliance and
message delivery efficiency. Each sender profile defines how messages are
delivered and categorized.

## View sender profiles

<Steps>
  <Step title="Open Channels">
    In the left pane of the RCS platform, click **Channels**.
  </Step>
  <Step title="Select RCS">
    Select **RCS**.
  </Step>
  <Step title="Open Sender Profiles">
    Click the **Sender Profiles** subtab.

    The Sender Profile details page is displayed with the following
    columns.
  </Step>
</Steps>

| Column Name | Description |
|---|---|
| **Profile Name** | The unique identifier of the sender. |
| **Message Type** | Specifies the purpose of the communication: **Promotional** (marketing campaigns, offers, and advertisements), **Transactional** (service-related updates, confirmations, and alerts), **OTP** (secure one-time passwords), or **No Message Type** (profiles without a defined category). |
| **Status** | Displays whether the profile is **Active** (enabled) or **Inactive** (temporarily disabled). |

<Note>
  The Sender Profiles list header also shows total, active, and inactive
  profile counts for the account.
</Note>
