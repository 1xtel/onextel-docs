**Config** in the OneXtel RCS platform allows you to view, search, and
download billing configurations for efficient rate management.

## Billing message types

In OneXtel, Billing defines the charges or credits applied for sending
different types of RCS messages. There are three types of RCS messages:

| Type | Description |
|---|---|
| **Basic** | Includes only text messages, with only 160 characters. |
| **Single** | Includes messages with URLs, videos/images with 160 or more characters. |
| **Other** | Besides Basic and Single messages. |

### Rates per region

The billing table lists rates for each region (like India, the UK) and
each message type.

### Billing type tabs

- **Assigned**: Rates set for the current user (non-editable).
- **Default**: Base rates inherited from the parent, i.e. Super Admin or
  Tenant (editable).
- **Custom**: Custom rates for a selected child entity (editable).

## Setting rates: Assigned

<Steps>
  <Step title="Open Channels > RCS">
    In the left pane of the RCS platform, click **Channels**, then select
    **RCS**.
  </Step>
  <Step title="Open Config > Billing">
    Click the **Config** tab, then click the **Billing** subtab.

    The RCS Billing details appear. By default, the **Assigned** Billing
    Type tab appears.
  </Step>
  <Step title="Export (optional)">
    Click **Download** to export the report.
  </Step>
</Steps>

## Setting rates: Default

<Steps>
  <Step title="Open Config > Billing">
    In the left pane of the RCS platform, click **Channels**, select
    **RCS**, click the **Config** tab, then click the **Billing** subtab.

    The RCS Billing details appear.
  </Step>
  <Step title="Select Default">
    On the right-hand side, select the **Default** Billing Type tab.
  </Step>
  <Step title="Search (optional)">
    Use the **Search** bar to find values. Only horizontal searches are
    supported; column-based searches are not allowed.
  </Step>
  <Step title="Upload rates">
    Click **+Upload** to add billing rates files.
  </Step>
  <Step title="Edit a rate">
    Double-click any value to edit the rate.
  </Step>
  <Step title="Apply or discard changes">
    Click **Reset to Default**, **Reset**, or **Save** to restore default
    values, discard unsaved changes, or save the updated billing
    configurations, respectively.
  </Step>
  <Step title="Export (optional)">
    Click **Download** to export the report.
  </Step>
</Steps>

## Billing flow

Rates cascade through the account hierarchy:

1. **Super Admin** sets base rates for Tenants.
2. **Tenant** can modify these rates for their TUCs.
3. **TUC** can further modify rates for its child TUCs.

Any overridden rates become independent of parent changes.

## Overridden concept

If a user changes a rate in the Custom tab, it becomes an override — the
rate no longer follows parent updates. Users can also reset to default to
revert to parent rates.

<Warning>
  File upload support: only Excel (`.xlsx`) and CSV files are supported.
  These files must contain rate tables in tabular format. Word files are
  not preferred because unstructured tables can't be read correctly.
</Warning>
