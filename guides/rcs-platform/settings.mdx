The RCS **Settings** subtab (under **Channels > RCS > Configurations**)
controls when messages can be sent, how often one recipient can be
messaged, and how customers opt out. Some settings are yours to change;
others are switched on for your account by your tenant administrator
(OneXtel or your reseller) — see
[Settings your administrator switches on](#settings-your-administrator-switches-on).

## Time Window

OneXtel Time Window allows customers to define specific time windows during
which RCS messages can be sent. This feature ensures that communications
are timely and compliant with business or regulatory requirements.

Once the configured window expires, further messages will either:

- Stop dispatching and be marked as failed with `900117`
  (`Platform_Timeout`), **or**
- Be scheduled for the next available window (e.g., next day), based on
  the customer's configured action.

<Steps>
  <Step title="Open Channels > RCS > Configurations > Settings">
    In the left pane, click **Channels**, select **RCS**, click the
    **Configurations** tab, then click the **Settings** subtab.
  </Step>
  <Step title="Enable Time Window">
    Toggle the **Time Window** switch to turn on the feature.

    The Time Window Configuration pop-up appears.
  </Step>
  <Step title="Enter configuration details">
    Fill in the mandatory and optional fields described below.
  </Step>
  <Step title="Save">
    Click **Save Configuration**.

    OneXtel RCS platform redirects to the Settings subtab.
  </Step>
</Steps>

### Mandatory configuration fields

| Field | Description | Task |
|---|---|---|
| **Start Time** | Start of the allowed time window. Applies to all days of the week. | Set the time from the dropdown list. |
| **End Time** | End of the allowed time window. Applies to all days of the week. | Set the time from the dropdown list. |
| **Preferred Action Post End Time** | What happens to messages still waiting when the window ends: **Send the remaining messages to the next day** (they go out from the next day's start time) or **Discard Messages** (they fail and are not delivered). | Select one option from the dropdown list. |

### Optional configuration fields

| Field | Description | Task |
|---|---|---|
| **Source** | Specifies the channel of message submissions — **WEB** or **API**. | Select the channel from the dropdown list. |
| **Sender Profile** | List of sender profiles configured for the account. | Select one or more sender profiles to filter the window based on specific senders. |
| **Message Type** | Message types (e.g., promotional, transactional), filtered based on the selected sender profiles. | Select one or more message types. |
| **Template Name** | Templates for the message type. | Select one or more template names. |
| **API Name** | A specific API endpoint used to submit messages. | Select one or more API names so the time window applies only to messages sent through those APIs. |

Leave the optional fields empty to cover all traffic. Sending stops 15
minutes before the end time.

## Frequency Capping

OneXtel's Frequency Capping feature allows customers to set and enforce
limits on the number of RCS messages sent to a specific mobile number
within a defined time window. It helps maintain compliance, prevent
spam-like behaviour, and reduce user fatigue. Messages over the cap are
blocked with `900115` (`Platform_Frequency_Limit_Reached`).

<Steps>
  <Step title="Open Channels > RCS > Configurations > Settings">
    In the left pane, click **Channels**, select **RCS**, click the
    **Configurations** tab, then click the **Settings** subtab.
  </Step>
  <Step title="Enable Frequency Capping">
    Toggle the **Frequency Capping** switch to turn on the feature.

    The Frequency Capping Configuration pop-up appears.
  </Step>
  <Step title="Enter configuration details">
    Fill in the mandatory and optional fields described below.
  </Step>
  <Step title="Save">
    Click **Save Configuration**.

    OneXtel RCS platform redirects to the Settings subtab.
  </Step>
</Steps>

### Mandatory configuration fields

| Field | Description | Task |
|---|---|---|
| **Number of Messages** | Maximum messages allowed to a single mobile number within the defined time window. | Enter the number. |
| **Time Window** | **Per Day**, or **Custom Time Period** — set the time (by default it is in HH:MM format). | Select any one option. |
| **Duplicate Category** | What counts towards the cap: **Template + Sender** (messages with the same template from the same sender profile) or **Sender** (all messages from the same sender profile). | Select one option. |

### Optional configuration fields

| Field | Description | Task |
|---|---|---|
| **Source** | Specifies the channel of message submissions — **WEB** or **API**. | Select the channel from the dropdown list. |
| **API Name** | List of available APIs used for sending messages. | Select one or more API names to apply the cap to those APIs. |
| **Sender Profile** | List of sender profiles configured for the account. | Select one or more sender profiles to filter the capping based on specific senders. |
| **Message Type** | Message types (e.g., promotional, transactional), filtered based on the selected sender profiles. | Select one or more message types. |
| **Template ID** | Template IDs linked to the selected message type; enabled only after a message type is chosen. | Select one or more template IDs. |

## Opt-In / Opt-Out

Lets customers start and stop your messages by keyword. Set the Opt-In and
Opt-Out configurations separately, each with:

| Field | Description |
|---|---|
| **Sender Profile** | The profile the keywords apply to. |
| **Message Type** | Transactional or Promotional. |
| **Keywords** (optional) | The words customers send, for example `STOP` and `START`. |

| Customer action | Result |
|---|---|
| Sends an exact opt-out keyword to the profile | The number goes on the opt-out list for that profile and message type. |
| Sends an exact opt-in keyword | The number goes on the opt-in list and comes off the opt-out list. |
| Sends any other message, or taps a button | The number comes off the opt-out list, if it is on it. |

Matching is exact and not case-sensitive. A number on both lists stays
opted out, and messages to it fail with `4013` (`User_Opt_Out`). Turning
the setting off keeps the lists for when you turn it on again.

The opt-out list appears under **Config > Blacklist Category** as
`rcs_optout_<sender profile>_<promotional | transactional>` — see
[Blacklist](/guides/platform/blacklist). To manage the lists from your own
systems, use the [Opt-in / opt-out API](/api-reference/rcs/opt-in-opt-out).

## Default Country Code

Pick a country, for example India (+91). The portal removes a leading `0`
or `00` and adds the country code to numbers saved without one.

## Message Limits (view only)

Shows the daily and monthly limits your tenant administrator has set for
your account.

## Settings your administrator switches on

| Setting | What it does for you |
|---|---|
| **Message Limits** | Daily and monthly caps on your volume. When a cap is reached, messages fail with `900121` (daily) or `900120` (monthly). Counters reset each calendar day and month. |
| **Billing** | Shows [Configurations > Billing](/guides/rcs-platform/billing-config) and adds a billing column to your reports. |
| **Template Auto Approval** | Approves your Jio templates automatically, within about 2 minutes. Vi templates still go to Vi. |
| **Capability Check** | Checks that each number can receive RCS before sending. Numbers that can't are failed at once with the operator's "RCS disabled" error, without using the operator's sending capacity. You can also call the RCS capability check API yourself. |
| **Sender Profile Pool** | Shows [Sender Pool](/guides/rcs-platform/sender-profiles#sender-pools). |
