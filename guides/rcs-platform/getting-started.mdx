## Prerequisites

- A **Username** and **Password** for the OneXtel RCS platform, issued by
  your administrator.
- Since RCS is managed by Google, your organization's RCS agent/brand must
  be signed up and configured on Google's RCS Business Messaging platform.
  An **Embedded Sign-up** option is available within OneXtel to configure
  RCS accounts.

## Signing in

<Steps>
  <Step title="Open the platform URL">
    Open a browser and access the OneXtel RCS Platform URL:
    `https://warcsqa.1xtel.dev`.
  </Step>
  <Step title="Enter credentials">
    Enter the **Username** and **Password** in the respective fields.
  </Step>
  <Step title="Accept the terms">
    Select the **'I accept the Terms and Conditions'** checkbox to agree to
    the terms.
  </Step>
  <Step title="Sign in">
    Click **Sign In**.
  </Step>
</Steps>

<Note>
  The sign-in URL shown above is the QA/staging environment referenced in
  the draft manual. Confirm your production sign-in URL with your account
  team.
</Note>

## Main Dashboard

The Dashboard provides a quick overview of activities and performance
within the platform. It tracks credits, message delivery statistics, and
campaign progress in real time.

After accessing the URL and logging in, the OneXtel WhatsApp and RCS
platform displays the Main Dashboard, which includes:

| Section | Description |
|---|---|
| **Credits Balance** | Displays the total available credits at the top right. |
| **Summary Overview** | Shows weekly and monthly reports for Submitted, Delivered, Failed, and Awaited messages. |
| **Today's Delivered Percent** | Displays the percentage of messages delivered for the day. |
| **Quick Stats** | Provides the number of messages submitted today, this week, and this month. |
| **Scheduled SMS** | Lists the upcoming scheduled SMS. |

## RCS Dashboard

Navigate to **Channels > RCS > Dashboard** to view the RCS-specific
dashboard. It includes:

| Section | Description |
|---|---|
| **Message Count** | Displays the total number of messages sent, successfully delivered, failed, and pending. |
| **Status Report (Last 7 Days)** | Provides a graphical view of daily sent, delivered, and failed messages. |
| **Take One Status** | Indicates whether the message flow mode is active or inactive. |
| **Latest Templates** | Lists the most recently used templates (e.g., Welcome Message, OTP Alert, Reminder). |
| **Campaign Overview** | Displays campaign details such as Campaign Name, Date, Type, Channel, Sent, Delivered, Failed, Pending, and Status (Completed, In Progress, Scheduled). |

<Tip>
  To create an RCS campaign, see
  [RCS Campaigns: Create a Campaign](/guides/rcs-campaigns/create-a-campaign).
</Tip>
