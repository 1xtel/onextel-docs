## Prerequisites

- A **Username** and **Password** for the OneXtel RCS platform, issued by
  your administrator.
- Your brand's RCS agent registered and approved with the operators, and set
  up as a sender profile in your account. OneXtel handles the operator
  registration — see [RCS Platform Overview](/guides/rcs-platform/overview).

## Signing in

Sign in to the OneXtel portal with the URL and credentials supplied for your account — see
[Signing in](/guides/platform/getting-started).

## Main Dashboard

The Dashboard provides a quick overview of activities and performance
within the platform. It tracks credits, message delivery statistics, and
campaign progress in real time.

After accessing the URL and logging in, the OneXtel WhatsApp and RCS
platform displays the Main Dashboard, which includes:

| Section | Description |
|---|---|
| **Credits Balance** | Displays the total available credits at the top right. |
| **Summary Overview** | Shows weekly and monthly reports for Submitted, Delivered, Failed, and Awaited messages. |
| **Today's Delivered Percent** | Displays the percentage of messages delivered for the day. |
| **Quick Stats** | Provides the number of messages submitted today, this week, and this month. |
| **Scheduled SMS** | Lists the upcoming scheduled SMS. |

## RCS Dashboard

Navigate to **Channels > RCS** to open the channel dashboard. A
**WhatsApp / RCS** switch at the top picks the channel. The dashboard shows
the last 7 days for your account and everything under it:

| Section | Description |
|---|---|
| **Tiles** | Sent, Delivered, Read, Failed, Incoming Data, Button Clicks and URL Clicks, each with its count and percentage. |
| **Status Report** | A day-by-day chart of Sent, Delivered and Failed, plus the Awaited count. |
| **Message Distribution** | Delivered, Failed, Pending and Total. |
| **Template Overview** | Each template's Sent, Delivered, Failed, Pending, Button Clicks Count and URL Clicks Count. |
| **Latest Templates** | The most recent templates. |

For other dates or a breakdown, use
[Summary Reports](/guides/rcs-platform/reports-summary).
