This page covers account-level configuration: profile settings, generating and managing API credentials, and system notifications.

## User profile settings

User Profile Settings let you customize your profile, preferences, and icon, update profile details, and change your password.

<Steps>
  <Step title="Open the user menu">
    In the right pane, click the user icon with your name.
  </Step>
</Steps>

Five options appear:

| Option | Description |
| --- | --- |
| My Account | Displays your profile details. |
| Alerts | Displays credit alerts. |
| Change Password | Resets your current password. |
| Login History | Displays your login history. |
| Log Out | Logs out of the account. |

### My Account

<Steps>
  <Step title="Open My Account">
    Click **My Account**.
  </Step>
  <Step title="Update your details">
    Update your name, email address, and mobile number.
  </Step>
  <Step title="Change your logo or icon (optional)">
    Click **Select File**. The system redirects you to the file manager — select the logo or icon file and click **Open**.
  </Step>
  <Step title="Save">
    Click **Save Changes**.
  </Step>
</Steps>

### Alerts

<Steps>
  <Step title="Open Alerts">
    Click **Alerts**.
  </Step>
  <Step title="Enable low credit alerts">
    Select **Low Credit Alert** to receive email notifications when your account's credits are running low.
  </Step>
</Steps>

### Change Password

<Steps>
  <Step title="Open Change Password">
    Click **Change Password**.
  </Step>
  <Step title="Enter passwords">
    Enter your current password, then enter and re-enter the new password.
  </Step>
  <Step title="Save">
    Click **Change Password**.
  </Step>
</Steps>

### Login History

<Steps>
  <Step title="Open Login History">
    Click **Login History**.
  </Step>
  <Step title="Show history">
    Click **Show Login History**. The platform displays the account's login IP addresses and login times.
  </Step>
</Steps>

## API

The **API** menu lets external applications programmatically send, receive, and manage messages, supporting integration, automation, and real-time communication across systems.

### Generate an API key

<Steps>
  <Step title="Open the API tab">
    In the left pane, click the **API** menu, then click the **API** tab.
  </Step>
  <Step title="Generate API">
    Click **+Generate API**.
  </Step>
  <Step title="Configure the key">
    In the pop-up, select the **Account Type**, select the **Scrub DND** checkbox if required, and enter a description for the API.
  </Step>
  <Step title="Submit">
    Click **Submit**. The platform generates the API key.
  </Step>
</Steps>

### View API keys

<Steps>
  <Step title="Open the API tab">
    In the left pane, click the **API** menu, then click the **API** tab.
  </Step>
  <Step title="Show API">
    Click **Show API**. The platform displays the APIs.
  </Step>
</Steps>

### Edit an API key

<Steps>
  <Step title="Open the API list">
    In the left pane, click **API**, then click **Show API** to display the APIs and their details.
  </Step>
  <Step title="Open the edit action">
    In the **Action** column, click the ellipsis (**...**) icon.
  </Step>
  <Step title="Save changes">
    Make the changes and click **Submit**. The platform updates the changes.
  </Step>
</Steps>

### Delete an API key

<Steps>
  <Step title="Open the API list">
    In the left pane, click **API**, then click **Show API** to display the APIs and their details.
  </Step>
  <Step title="Delete">
    In the **Action** column, click the **Delete** icon.
  </Step>
  <Step title="Submit">
    Make the changes and click **Submit**. The platform updates the changes.
  </Step>
</Steps>

<Note>
  Account type cannot be updated once an API key is created.
</Note>

## Notifications

The **Notification** menu supports creation and management of system-wide messages. It displays the subject, content, target users, and creation time, and provides options to view or remove notifications.

### Add a notification

<Steps>
  <Step title="Open Notification">
    In the left pane, click **Notification**.
  </Step>
  <Step title="Add notification">
    Click **+Add Notification**.
  </Step>
  <Step title="Enter details">
    In the pop-up, enter the **Subject** and **Content** of the notification, then select whether it applies to a particular TUC or to all.
  </Step>
  <Step title="Save">
    Click **Add**. The platform adds the notification.
  </Step>
</Steps>

### View notifications

<Steps>
  <Step title="Open Notification">
    In the left pane, click **Notification**.
  </Step>
  <Step title="Show notifications">
    Click **Show Notification**. The platform displays the list of notifications.
  </Step>
</Steps>

### Edit a notification

<Steps>
  <Step title="Open the notification list">
    In the left pane, click the **Notification** menu, then click **Show Notification** to display the list of notifications.
  </Step>
  <Step title="Open the edit action">
    In the **Action** column, click the ellipsis (**...**) icon.
  </Step>
  <Step title="Save changes">
    Make the changes and click **Update**. The platform updates the notification.
  </Step>
</Steps>

### Delete a notification

<Steps>
  <Step title="Open the notification list">
    In the left pane, click the **Notification** menu, then click **Show Notification** to display the list of notifications.
  </Step>
  <Step title="Delete">
    In the **Action** column, click the **Delete** icon in front of the notification you want to remove.
  </Step>
  <Step title="Confirm">
    A warning appears to confirm removal. Click **Delete**. The platform removes the notification.
  </Step>
</Steps>
