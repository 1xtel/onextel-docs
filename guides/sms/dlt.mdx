title: "DLT Registration"
description: "Register entity IDs, sender IDs, and message templates for TRAI-mandated DLT compliance before sending SMS in India."
---

**DLT (Distributed Ledger Technology)** is a TRAI-mandated system in India that brings
transparency to commercial SMS and prevents spam. Before you can send, your business, your
sender IDs, and every message template must be registered on a DLT platform.

Registration happens in a fixed order, because each step depends on the one before it:

<Steps>
  <Step title="Register your entity">
    Your business is identified by a 19-digit government-issued **Entity ID**.
  </Step>
  <Step title="Register your sender IDs">
    Each sender ID is linked to an entity and approved individually.
  </Step>
  <Step title="Register your templates">
    Each template is linked to both an entity and a sender ID, and carries a consent type.
  </Step>
</Steps>

Everything below lives under **DLT** in the left pane.

<Note>
DLT applies to SMS sent within India. For international SMS, see
[Sender IDs](/guides/sms/sender-id) and [Templates](/guides/sms/templates).
</Note>

## Entity IDs

An Entity ID uniquely identifies your business using a 19-digit government-issued number,
verifying its identity for sending SMS through telecom operators under TRAI rules.

### Add an Entity ID

<Steps>
  <Step title="Open the Entity IDs tab">
    Click **DLT**, select the **Entity IDs** tab, and click **+ Add Entity Id**.
  </Step>
  <Step title="Enter the details">
    | Field | Description |
    | --- | --- |
    | Entity ID | The unique identifier assigned to your registered business |
    | Entity Name | The registered name of the business that intends to send SMS |
  </Step>
  <Step title="Add">
    Click **Add**.
  </Step>
</Steps>

<Frame caption="Add Entity ID">
  <img src="/images/sms/dlt-add-entity-id.png" alt="Add Entity ID dialog with Entity ID and Entity Name fields" />
</Frame>

<Warning>
**Entity Name must match the name used during DLT registration exactly.** It is linked to the
Entity ID for authentication and compliance — a mismatch fails validation downstream, not at the
point you enter it.
</Warning>

### View, edit, and delete

Click **DLT → Entity IDs → Show Entity Id** to list your entities with their ID, name, and
status.

To edit, click the **Ellipsis** icon in the Action column, make your changes, and click
**Update**. To delete, click the **Delete** icon and confirm in the warning dialog.

## Sender IDs

A Sender ID identifies the origin of your messages to recipients, and is also used to filter
report data by sender.

### Add a Sender ID

<Steps>
  <Step title="Open the Sender IDs tab">
    Click **DLT**, select the **Sender IDs** tab, and click **+ Add Sender ID**.
  </Step>
  <Step title="Enter the Sender ID">
    Enter the sender ID, then select the **Entity Name** it belongs to from the dropdown.
  </Step>
  <Step title="Set the options">
    | Option | Effect |
    | --- | --- |
    | Set as Default | This sender ID is used by default for message sending |
    | Is Govt. Exempted | Marks the sender ID as exempted under government regulations |
  </Step>
  <Step title="Add">
    Click **Add**.
  </Step>
</Steps>

<Frame caption="Add Sender ID">
  <img src="/images/sms/dlt-add-sender-id.png" alt="Add Sender ID dialog with Sender ID field, Entity Name selector, and Set as Default and Is Govt. Exempted options" />
</Frame>

<Note>
The form accepts 3 to 15 characters, but registered Indian sender IDs are six characters. Use
the value exactly as approved on the DLT platform.
</Note>

### View Sender IDs

Click **DLT → Show Sender ID**. The table shows:

| Column | Description |
| --- | --- |
| Sender ID | The government-issued sender ID |
| Entity ID | The entity this sender belongs to |
| Approved By | Who approved the registration |
| Approved On | Date of approval |
| Status | `Approved` or `Rejected` |
| Default | Whether it is the default for sending |
| Action | Update or remove the entry |

<Note>
A sender ID only works once **Status** reads `Approved`. Adding it here does not approve it —
check the status before building a campaign around it.
</Note>

### Edit and delete

Click **Show Sender ID**, then the **Ellipsis** icon in the Action column to edit and
**Update**, or the **Delete** icon and confirm to remove.

## Templates

Templates are the predefined, approved message formats you are permitted to send. Every DLT
template is bound to an entity, a sender ID, and a consent type.

### Add a template

<Steps>
  <Step title="Open the Template tab">
    Click **DLT**, select the **Template** tab, and click **+ Add Template**.
  </Step>
  <Step title="Enter the details">
    | Field | Description |
    | --- | --- |
    | Template Name | A name for the template |
    | Template ID | The unique identifier assigned to the template, used for reference and tracking |
    | Select Type | The consent category — see below |
    | Select Entity ID | The registered entity |
    | Select Sender ID | The sender ID this template sends from |
    | Description | A short description |
    | Content | The SMS content |
  </Step>
  <Step title="Add">
    Click **Add**.
  </Step>
</Steps>

### Template types

| Type | Use for |
| --- | --- |
| **Promo** | Promotional messages |
| **Service Implicit** | Service-related messages that do not require explicit user consent |
| **Service Explicit** | Service-related messages that require explicit user consent |

<Warning>
The type determines who may legally receive the message and when. Registering promotional
content as Service Implicit to bypass DND filtering is a compliance breach, not a shortcut, and
risks the sender ID being blocked.
</Warning>

### View and search templates

On the **Template** tab, set a **Limit** and **Search Type**, then click **Search**. Use
**Reset** to clear the filters. The list shows template name, sender ID, entity ID, template ID,
content, date added, and type.

### Delete templates

<Steps>
  <Step title="Find the templates">
    Click **DLT → Template → Search**.
  </Step>
  <Step title="Delete">
    Use the **Delete** icon in the Action column for one template, **Delete Selected** for the
    templates you have ticked, or **Delete All** to remove every template at once.
  </Step>
  <Step title="Confirm">
    Confirm in the warning dialog.
  </Step>
</Steps>

<Warning>
**Delete All** removes every template, not just those matching your current search. A deleted
template must be re-registered on the DLT platform before it can be used again.
</Warning>

## Bulk upload

Upload many templates at once instead of adding them one at a time.

<Steps>
  <Step title="Open the Bulk Upload tab">
    Click **DLT**, then select the **Bulk Upload** tab.
  </Step>
  <Step title="Set the entity and operator">
    | Field | Description |
    | --- | --- |
    | Entity ID | The entity these templates are uploaded for |
    | Operator | The operator for template submission |
  </Step>
  <Step title="Get the format right">
    Use **Download Generic Sample File** to get a correctly formatted reference file before
    preparing your own.
  </Step>
  <Step title="Upload">
    Click **Choose File**, select your file, then click **Save Templates**.
  </Step>
</Steps>
