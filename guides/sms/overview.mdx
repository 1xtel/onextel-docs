The OneXtel International platform is a business communication platform that enables brands to
create connected customer experiences through integrated telecommunication. Use it to send SMS
to international recipients, run bulk campaigns, manage templates and Sender IDs, and analyze
delivery through detailed reports.

This guide covers the end-user portal: sending SMS, managing campaigns, generating reports,
maintaining phonebooks, and configuring account settings.

## Signing in

Sign in to the OneXtel International platform to perform messaging operations.

<Steps>
  <Step title="Open the platform URL">
    Open a web browser and go to the OneXtel International platform URL provided by your
    account team.
  </Step>
  <Step title="Enter your credentials">
    Enter your **Username** and **Password** for your designated role.
  </Step>
  <Step title="Accept the terms">
    Select the **I accept the Terms and Conditions** checkbox.
  </Step>
  <Step title="Sign in">
    Click **Sign In**. After successful authentication, the Dashboard appears.
  </Step>
</Steps>

## Dashboard

The dashboard displays message data received from customers on an hourly, daily, and monthly
basis in a grid format. It provides a clean, user-friendly interface for real-time SMS
monitoring and management.

## Key terms

| Term | Definition |
| --- | --- |
| TUC (Tenant User Customer) | A primary account that manages and delivers SMS services independently. |
| Child TUC | A secondary account that manages SMS services under the primary account. |
| Reseller / Sub-account Module | An account that manages multiple SMS accounts. |
| Credits | The total number of messages an account can send. One credit equals one 160-character message. Unicode or long messages consume multiple credits based on the number of message segments per request. |
| UU ID | A unique ID that identifies each SMS sent to recipients. |

<Note>
  Credits are consumed per message segment. A message longer than 160 characters is split
  into multiple parts, and each part consumes one credit.
</Note>

## SMS sending options

The platform offers five SMS categories under **+New SMS**:

| Category | Use it to |
| --- | --- |
| Quick English SMS | Send text messages, schedule messages, and import contacts from phonebooks or notepads. |
| Quick Unicode / Multilingual SMS | Send text messages in multiple languages, schedule messages, and import contacts. |
| Dynamic SMS | Send messages with multiple variables, importing recipient numbers and variable data from Excel sheets. |
| Multiple Dynamic SMS | Send messages using multiple templates from a single Excel sheet for large-scale, multi-template messaging. |
| Campaign SMS | Run bulk SMS campaigns with multiple variables and recipient numbers imported from Excel sheets. |

See [Send SMS](/guides/sms/send-sms) for Quick English, Quick Unicode/Multilingual, Dynamic, and
Multiple Dynamic SMS, and [Campaigns](/guides/sms/campaigns) for Campaign SMS and campaign
management.
