title: "Send SMS"
description: "Send Quick English, Quick Unicode/Multilingual, Dynamic, and Multiple Dynamic SMS from the OneXtel International platform."
---

The **+New SMS** menu in the left pane offers four ways to send SMS outside of a full campaign: Quick English SMS, Quick Unicode/Multilingual SMS, Dynamic SMS, and Multiple Dynamic SMS. For bulk campaigns sent through the **Campaign** module, see [Campaigns](/guides/sms/campaigns).

## Quick English SMS

Send text messages to up to 100,000 recipients. A single-part SMS supports up to 100,000 recipients; a two-part SMS supports up to 50,000 recipients. Recipient limits decrease as the number of message parts increases. You can schedule messages for delivery at specific times, and import contacts from the phonebook or paste recipient lists directly into the notepad.

<Steps>
  <Step title="Open Quick English SMS">
    In the left pane, click **+New SMS**, then click **Quick English SMS**.
  </Step>
  <Step title="Select campaign and Sender ID">
    Select the campaign name from the dropdown list, then select the Sender ID from the dropdown list.
  </Step>
  <Step title="Add recipients">
    Enter recipient contact details, separating each contact by pressing **Enter**. Alternatively, import the recipient list from the phonebook by selecting the required group name under **Groups**.
  </Step>
  <Step title="Remove duplicates (optional)">
    Select **Remove Duplicate Numbers** to refine recipient data automatically.
  </Step>
  <Step title="Insert a template (optional)">
    Click **Insert Template**. In the pop-up, select the template filter from the dropdown list — use **Search** to search for a template, or the dropdown to select one directly. Enter the template content and click **Select**.
  </Step>
  <Step title="Insert a URL (optional)">
    Click **Insert URL**, select the domain, and enter the URL you want to include in the SMS. Select **Get location** if you want to track the recipient's location, then select **Insert URL**.
  </Step>
  <Step title="Set message options">
    Select the appropriate options for the message (see table below).
  </Step>
  <Step title="Send">
    Click **Send**. A confirmation pop-up appears with a summary of the message details, including invalid numbers, blacklisted numbers, SMS character count, credits used, DND numbers, and duplicate numbers. Click **Send Now** to dispatch the message.
  </Step>
</Steps>

| Option | Description |
| --- | --- |
| Allow Multi Part SMS | Messages over 160 characters are split into multiple parts. |
| Send as Flash SMS | Message appears on the recipient's screen rather than in the inbox. |

## Dynamic SMS

Send messages with multiple variables, importing recipient numbers and variable data directly from an Excel sheet. Reach up to 2,000,000 recipients — a single-part SMS supports up to 2,000,000 recipients, a two-part SMS supports up to 1,000,000 recipients, and recipient limits decrease as the number of message parts increases.

<Steps>
  <Step title="Open Dynamic SMS">
    In the left pane, click **+New SMS**, then click **Dynamic SMS**.
  </Step>
  <Step title="Download and fill the sample file">
    Click **Download Sample File**, select the preferred file format, and click **Save File**. Enter all required information in the appropriate columns of the Excel sheet.
  </Step>
  <Step title="Upload the file">
    Click **Choose File** and upload the completed Excel file.
  </Step>
  <Step title="Select campaign and Sender ID">
    Select the appropriate campaign name from the dropdown list, then select the Sender ID from the dropdown list.
  </Step>
  <Step title="Select the recipient column">
    Select the **Recipient Column** from the dropdown list — this is the column in the uploaded Excel file that contains the recipient mobile numbers.
  </Step>
  <Step title="Remove duplicates (optional)">
    Select **Remove Duplicate Numbers** to refine recipient data automatically.
  </Step>
  <Step title="Insert a template (optional)">
    Click **Insert Template**. In the pop-up, select the template filter from the dropdown list — use **Search** to search for a template, or the dropdown to select one directly. Enter the template content and click **Select**.
  </Step>
  <Step title="Select a language">
    Select a language from the dropdown list.
  </Step>
  <Step title="Insert a URL (optional)">
    Click **Insert URL**, select the domain, and enter the URL you want to include in the SMS. Select **Get location** if you want to track the recipient's location, then select **Insert URL**.
  </Step>
  <Step title="Set message options">
    Select the appropriate options for the message (see table below).
  </Step>
  <Step title="Send">
    Click **Send**. A confirmation pop-up appears with a summary of the message details, including invalid numbers, blacklisted numbers, SMS character count, credits used, DND numbers, and duplicate numbers. Click **Send Now** to dispatch the message.
  </Step>
</Steps>

## Multiple Dynamic SMS

Send messages using multiple templates from a single Excel sheet, importing recipient numbers directly from Excel. Supports large-scale, multi-template messaging for up to 2,000,000 recipients (limits vary based on SMS parts).

<Steps>
  <Step title="Open Multiple Dynamic SMS">
    In the left pane, click **+New SMS**, then click **Multiple Dynamic SMS**.
  </Step>
  <Step title="Download and fill the sample file">
    Click **Download Sample File**, select the preferred file format, and click **Save File**. Enter all required information in the appropriate columns of the Excel sheet.
  </Step>
  <Step title="Upload the file">
    Click **Choose File** and upload the completed Excel file.
  </Step>
  <Step title="Select campaign and Sender ID">
    Select the appropriate campaign name from the dropdown list, then select the Sender ID from the dropdown list.
  </Step>
  <Step title="Select the recipient and template columns">
    Select the **Recipient Column** from the dropdown list — the column containing recipient mobile numbers. Then select the **Template Content Column** — the column containing the SMS message or template content corresponding to each recipient.
  </Step>
  <Step title="Set delivery options">
    Select the appropriate options (see table below).
  </Step>
  <Step title="Send">
    Click **Send**. A confirmation pop-up appears with a summary of the message details, including invalid numbers, blacklisted numbers, SMS character count, credits used, DND numbers, and duplicate numbers. Click **Send Now** to dispatch the message.
  </Step>
</Steps>

| Option | Description |
| --- | --- |
| Remove Duplicate Numbers | Removes duplicate or repeated mobile numbers from the recipient list. |
| Shorten all URLs | Automatically shortens long URLs included in the variables. |
| Schedule SMS | Schedules SMS for future delivery — click **Schedule SMS** and select the required date and time. |
| Scrub DND | Excludes recipients who have opted in to DND (Do Not Disturb) mode. |
| Recurrence | Schedules SMS delivery on specific days at a specified time. |

<Note>
  For all four SMS types, the post-send confirmation pop-up shows invalid numbers, blacklisted
  numbers, SMS character count, credits used, DND numbers, and duplicate numbers before you
  confirm with **Send Now**.
</Note>
