The Campaign feature in OneXtel creates, manages, and sends bulk or targeted
messages across multiple channels, including WhatsApp and RCS.

## Open the campaigns dashboard

<Steps>
  <Step title="Open Channels">
    In the left pane of the portal, click **Channels**.
  </Step>
  <Step title="Select a channel">
    Select a channel.
  </Step>
  <Step title="Open Campaigns">
    Click **Campaigns**. The campaigns dashboard appears.
  </Step>
</Steps>

## What the dashboard shows

The campaigns dashboard displays all campaigns created for the WhatsApp and
RCS channels as cards. Each card shows the created date, channel, status,
campaign name, template, uploaded file, number of records, creator and
scheduled time. A `Stopped` campaign also shows its **Failure Reason**.

### Dashboard actions

| Action | Where |
| --- | --- |
| Search by campaign name or ID | Search box at the top of the dashboard. |
| Filter by channel, template, username, status or date | Filters next to the search box. **Clear all** resets them. |
| Reload the latest statuses | **Refresh** button in the top right. |
| Clone an existing campaign | **Clone Campaign** button in the top right. |
| Create a new campaign | **New Campaign** button in the top right. |

### Campaign statuses and actions

The buttons on each card depend on the campaign's status.

| Status | Actions |
| --- | --- |
| `Created` / `Draft` (not launched) | Edit, Clone, Delete |
| `Scheduled` | View, Clone, Reschedule, Cancel |
| `Running` | View, Clone, Pause, Stop |
| `Paused` | View, Clone, Resume, Stop |
| `Completed` / `Stopped` | View, Clone |
| `Cancelled` / `Failed` | View, Clone |
| `Pending` / `Rejected` (maker-checker) | Edit, View, Clone |
| `Approved` (maker-checker) | Edit, View, Clone, Launch (checker only) |

**View** opens a read-only copy of the campaign set-up. It doesn't show
results — use [Summary Reports](/guides/rcs-platform/reports-summary#report-on-one-campaign)
for those.

<Note>
  The `Pending`, `Rejected` and `Approved` statuses appear only when
  maker-checker is switched on for your account. See
  [Roles](/guides/platform/roles#campaign-maker-checker).
</Note>
