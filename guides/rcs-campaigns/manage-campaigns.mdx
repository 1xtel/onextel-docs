The Campaign feature in OneXtel creates, manages, and sends bulk or targeted
messages across multiple channels, including WhatsApp and RCS.

## Open the campaigns dashboard

<Steps>
  <Step title="Open Channels">
    In the left pane of the WhatsApp-RCS platform, click **Channels**.
  </Step>
  <Step title="Select a channel">
    Select a channel.
  </Step>
  <Step title="Open Campaigns">
    Click **Campaigns**. The campaigns dashboard appears.
  </Step>
</Steps>

## What the dashboard shows

- The Campaigns dashboard displays all campaigns created for the WhatsApp and
  RCS channels.
- Each campaign card shows the campaign name, template used, uploaded file,
  number of records, creation date, creator, and status.
- The dashboard allows searching, filtering by channel or type, cloning
  existing campaigns, and creating new campaigns using the **New Campaign**
  button.

### Campaign statuses

| Status | Meaning |
| --- | --- |
| Created | The campaign has been created. |
| Draft | The campaign is saved but not yet launched. |
| Completed | The campaign has finished sending. |

### Dashboard actions

| Action | Where |
| --- | --- |
| Search campaigns | Search box at the top of the dashboard. |
| Filter by channel, template, type, or date | Dropdown filters next to the search box. |
| Clone an existing campaign | **Clone Campaign** button in the top-right. |
| Create a new campaign | **New Campaign** button in the top-right. |
